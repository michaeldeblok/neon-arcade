# Neon Arcade

Four single-file neon arcade games. Each page is one HTML file with its own graphics, audio, and touch controls.

Play them at <https://michaeldeblok.github.io/neon-arcade/>.

| Game | Open |
| --- | --- |
| Tetris // Afterglow | [neon-tetris.html](https://michaeldeblok.github.io/neon-arcade/neon-tetris.html) |
| Neon Serpent | [neon-serpent.html](https://michaeldeblok.github.io/neon-arcade/neon-serpent.html) |
| Arkanoid // Afterglow | [neon-arkanoid.html](https://michaeldeblok.github.io/neon-arcade/neon-arkanoid.html) |
| Space Harrier // Synthrift | [space-harrier.html](https://michaeldeblok.github.io/neon-arcade/space-harrier.html) |

Space starts a run. Headphones are worth it.

Space Harrier: fly the plain with the mouse, arrows or a drag; auto-fire is armed and `A` toggles it, `P` pauses, `M` mutes. Every fourth sector the colossus rises.
